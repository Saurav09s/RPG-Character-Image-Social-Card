** RPG Character Image Social Card **
---------------------------------------------------------------------
** App Features **
1. Create a RPG character of any image you like
2. The RPG character has a embedded URL of your social page.
3. On scanning it anyone can visit your social media account.
4. The created RPG character are stored in your collection which you can download, modify and delete.

** Tech Stack **
1. Frontend: ReactJs, HTML, CSS
2. Backend: NodeJs
3. Authentication: OAuth, JWT
4. APIs & Tools: Nano Banana, Git, Docker
